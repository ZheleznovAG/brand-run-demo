# Brand Run — демо промо-игры

Сборка Unity WebGL демо-игры для вымышленной кофейни «Зерно»: раннер на одно касание с промокодом за 300 очков. Работает в браузере и как Telegram Mini App.

Играть: https://zheleznovag.github.io/brand-run-demo/

Здесь только собранная игра. Бренд, цвета, порог очков и промокод задаются в `index.html` (объект `BRAND`).
